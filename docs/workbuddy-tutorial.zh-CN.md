## 1. 安装

把下面两行发送给 WorkBuddy：

```text
请安装这个 MRO 询价匹配 Skill：
https://github.com/cfanlu/mro-inquiry-match/tree/main/skills/mro-inquiry-match
```

等到安装完成，再继续。

## 2. 获取并配置 Key

安装 Skill 后，缺少密钥时向 Agent 提供用于接收访问邮件的邮箱；也可打开 [邮箱接入](https://mro-api.iwilley.com/email-access)，填写邮箱后点击“发送访问邮件”，通过弹出的行为验证后自动发信。点击邮件链接，在网页完成阿里云行为验证后，自动激活、登录并跳到“API 密钥”页面。找到已启用的密钥，点击右侧“复制密钥”按钮，显示“已复制”后回到 WorkBuddy 私密对话，粘贴完整密钥并发送。不要复制页面上带星号的遮罩文字。已有旧账号使用原方式登录，再复制现有密钥或创建密钥；MFA 仍需完成。

邮件链接 15 分钟有效；频率异常时先在网页验证再发信。新版视频已按邮箱接入流程更新，复制按钮采用真实页面截图。余额不足时按 Agent 提示打开[钱包](https://mro-api.iwilley.com/wallet)充值，充值后告诉 Agent 继续。

在自己的 WorkBuddy 对话框发送：

```text
请使用这个 MRO API Key，帮我完成配置并检查是否可用。
API Key：<替换为自己复制的完整密钥>
```

让 WorkBuddy 完成配置并反馈验证结果，然后确认账户可用的数据源。数据可来自本公司的商品资料或已接入的公网主流 MRO 平台公开商品数据。不要把真实 Key 提交到 GitHub、公开 Issue 或公开录屏。

## 3. 提交原始询价 Excel

添加文件并预览确认，再发送：

```text
使用这个技能处理这个询价文件。
保留原始询价工作表，匹配结果按需求分组：父行保留原始需求，子行逐件列出首选和备选。
展示型号、单位、数量、参考单价、匹配状态、依据及待确认项；产品名称保留详情链接，最后导出 Excel。
```

视频从 00:57 开始讲解原始文件要求：每行一个产品需求，只有产品描述必填。型号、品牌、数量、单位等其他列全部可选，有就填，没有可留空；列顺序不限，无需固定模板。随后展示本次10条原始需求；01:13—01:24使用WorkBuddy真实输入框和已发送消息演示附件提交。截图中的8条小样仅演示操作，实际请提交自己的文件。

处理完成后，打开回复中的结果 Excel，按下列顺序复核。

## 4. 怎样看分组结果

1. **看父行需求**：浅蓝色父行保留原始描述、型号、品牌、单位和数量；不要把需求数量当作候选价格或商品属性。
2. **看组内候选**：子行逐条列出首选、备选或替代推荐；产品名称上的链接用于进一步查看详情。左侧 Excel 分组按钮可用于收起或展开候选。
3. **核对型号和参考单价**：视频中的两个同型号候选显示 132 元及 181.60 元；这只是历史检索参考价，不能据此认定当前市场完整价格区间。
4. **单独核查替代款**：123 元的候选属于不同型号，原结果指出表盘刻度存在差异，需确认可接受后才考虑替代。不能将它直接当作同型号最低价。
5. **阅读依据和待确认项**：即使状态为精确匹配，仍应核查计价单位、包装、税运、库存、交期和适用性，再与业务部门或供应商确认。

本片为真实表格摘录、局部放大及操作说明，具体数据平台名称未展示。匹配结果用于辅助采购复核，不是直接采购结论，也不保证节省比例。

## 试用

先拿五到十条自己的脱敏需求试一次。保留原文中的缺失和冲突，让智能体把需要确认的问题列出来。公开仓库不附此次内部原始询价工作簿。
