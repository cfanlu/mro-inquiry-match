安装技能：
请安装这个MRO询价匹配Skill：
https://github.com/cfanlu/mro-inquiry-match/tree/main/skills/mro-inquiry-match

复制MRO API Key后，在WorkBuddy对话框发送：
请使用这个MRO API Key，帮我完成配置并检查是否可用。
API Key：<粘贴刚复制的完整密钥>

添加原始Excel后提交：
使用这个技能处理这个询价文件。
保留原始询价工作表，匹配结果按需求分组：父行保留原始需求，子行逐件列出首选和备选。
展示型号、单位、数量、参考单价、匹配状态、依据及待确认项；产品名称保留详情链接，最后导出Excel。

API平台：https://mro-api.iwilley.com/
没有 API Key 时，向 Agent 提供接收访问邮件的邮箱；点击邮件链接，在网页完成阿里云行为验证后自动激活、登录并进入 API 密钥页面。找到 MRO Skill 密钥，点击右侧“复制密钥”，显示“已复制”后返回 WorkBuddy 私密对话，粘贴完整密钥并发送。不要复制带星号的遮罩文字。
也可访问 https://mro-api.iwilley.com/email-access，填写邮箱后点击“发送访问邮件”，通过弹出的行为验证后自动发信。已有旧账号使用原方式登录，MFA 仍需完成；没有可用密钥时在 API 密钥页面创建。
余额不足时访问 https://mro-api.iwilley.com/wallet 充值，再告诉 Agent 继续；保留已完成的匹配结果。
